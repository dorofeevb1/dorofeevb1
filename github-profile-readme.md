## Projects

### Universal Nurse — АРМ медицинского персонала
> Angular 15 | NgRx | Keycloak | TypeScript

Универсальное автоматизированное рабочее место для медсестёр и врачей.
Объединяет несколько специализированных модулей: стомы, зонды, аптечки, лабораторные тесты, назначения.
Монорепозиторий с shared-библиотеками и динамической линковкой модулей.

---

### BeautyStyleService — Маркетплейс бьюти-услуг
> Angular 21 | Django 5 | Ionic + Capacitor | PostgreSQL | Docker

Полноценная платформа бронирования: поиск мастеров по геолокации, онлайн-запись, оплата через YooKassa, чат, AI-анализ фото.
Монорепозиторий: веб + мобильное приложение (iOS/Android) + бэкенд.

---

### BrioTradeLogistic — Платформа торговой логистики
> Angular 15 | Django REST | PostgreSQL | Celery | Docker

Система управления товарами, продажами и заказами.
Импорт/экспорт данных из Excel, мультиязычность (RU/EN/ZH), асинхронная обработка задач.

---

### FrontPulse — Дашборд мониторинга
> Angular 15 | PrimeNG | Chart.js | TailwindCSS

Панель управления для мониторинга сервисов: графики в реальном времени, генерация отчётов, управление ресурсами и уведомлениями.

---

### ADRIA QR — Верификация продукции
> Vue 3 | Vite | TypeScript | SCSS

Промо-приложение для проверки подлинности контактных линз ADRIA через QR-код.
Сканирование → регистрация → SMS-верификация → начисление бонусов.

---

### Twitch AI Bot — Умный чат-бот
> Python 3 | Claude API | twitchio | PostgreSQL | Docker

AI-бот для Twitch-чатов на базе Claude. Отвечает на упоминания, распознаёт агрессию, автомодерация, семантический поиск по истории канала, веб-дашборд.

---

### DropNRead — Утилита для LLM
> Vanilla JS | HTML5 | CSS3

Браузерный инструмент, который объединяет файлы проекта в один текст для отправки в ChatGPT/Claude/Gemini.
Drag & drop, подсчёт токенов, удаление комментариев, настраиваемые фильтры.
